# AGENTS.md

Pile : React Router, Vite, TypeScript, Supabase et Capacitor, gérés avec pnpm 11.

Commandes documentées dans README.md et package.json :
- Installer : pnpm install --frozen-lockfile
- Développer : pnpm dev
- Vérifier : pnpm typecheck
- Tester : pnpm test
- Construire : pnpm build
- Service local : pnpm start

Lire README.md et docs/CDC-MASTER.md avant de modifier l'ouverture publique, les emails, l'authentification ou l'administration. Respecter les trois portes humaines existantes : sortie externe, suppression ou écrasement de données, dépense. Préserver les garde-fous du projet.
