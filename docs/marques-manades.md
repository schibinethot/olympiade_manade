# Marques à feu des manades

Les cinq marques de l’édition 2026 ont été identifiées dans le répertoire du
[Livre généalogique de la Raço di Biòu (LGRB)](https://lgrb.fr/les-manades/),
consulté le 17 octobre 2026. Chaque fiche associe le nom de la manade à une
image intitulée « Marque à feu ». Ce sont ces fers qui remplacent les initiales
provisoires dans l’interface.

| Lafon | `public/marques/manades/lafon.jpg` | [Lafon_page-0001.jpg](https://lgrb.fr/wp-content/uploads/2020/06/Lafon_page-0001.jpg) |

Le répertoire nomme la fiche de Robert Michel « Michel Robert » ; elle identifie
Robert Michel comme propriétaire et le Domaine de Fangousse à Lattes comme
adresse. Le [site du Domaine de Fangouse](https://domainedefangouse.fr/)
confirme l’appellation « Manade Robert Michel ».

Le [site de la manade Lafon](https://www.manade-lafon.com/manade-lafon-historique.html)
décrit également sa marque comme un iris stylisé dans un ovale.

Les fichiers JPEG de 237 × 237 pixels sont les originaux téléchargés, sans
redessin ni génération. Ils sont servis localement ; les modes de fusion CSS
permettent leur affichage sur les fonds clairs et sombres. Une initiale reste
utilisée lorsqu’aucune marque n’a été identifiée pour une manade.

Cette provenance identifie les dessins ; elle ne constitue pas une licence libre
ni un accord de leurs propriétaires. Aucun accord de réutilisation n’est joint
à ces fichiers dans le dépôt.
